The **Stock Portfolio Tracker** is a Python-based project designed to help investors and finance enthusiasts manage their stock holdings effortlessly. As a **B.Tech 2nd-year student**, I built this tool to simplify real-time stock tracking using APIs like Yahoo Finance (`yfinance`), Alpha Vantage, and IEX Cloud. Instead of manually checking stock prices or relying on outdated spreadsheets, this tracker automates the process, fetching live market data and calculating total portfolio value instantly.
The idea for this project came from my curiosity about stock markets and the importance of knowing investment trends. Whether you're a casual investor or someone diving into financial analysis, this tool makes portfolio tracking more efficient. It retrieves stock prices dynamically, ensuring you always have **accurate and up-to-date information**. Even if one API fails, the tracker intelligently switches to another source, making it **reliable and error-proof**.
Beyond just numbers, I wanted to make this project **user-friendly**, so it displays both **company names and ticker symbols**, making the stock data more intuitive. The system is structured in a way that it can easily be expanded in the future—maybe integrating **historical analysis, graphical trends**, or even AI-powered stock predictions!
For me, this isn’t just a coding exercise—it’s a hands-on experience that bridges **programming and financial markets**, reinforcing both **technical skills** and **practical applications** in real-world investing. It’s a project that not only enhances coding proficiency but also deepens financial knowledge—something every engineer should explore!
